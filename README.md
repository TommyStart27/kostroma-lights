# Светофоры Костромы

Карта Костромы с таймингами светофоров и маршрутами, которые учитывают ожидание на красном.
Работает в браузере на ПК и устанавливается на iPhone/Android как приложение.

## Что умеет

- **Карта.** Улицы, дворы, вода и подписи, всё из OpenStreetMap. При первом запуске карта скачивается (около минуты) и дальше работает офлайн.
- **Моё местоположение.** Кнопка ◎. На телефоне точность по GPS, на ПК примерная.
- **Поиск** улиц и светофоров по номеру.
- **Маршрут A → B** на авто или пешком, в двух вариантах:
  - «Быстрее» учитывает ожидание на светофорах: с вашими таймингами точно, без них по среднему;
  - «Короче» выбирает минимальное расстояние.

  Показывает время в пути, прибытие и список светофоров с прогнозом «зелёный / ждать N с».
- **129 светофорных объектов** Костромы. Для каждого можно ввести зелёный, жёлтый и красный, улицу и момент включения зелёного. Цвета на карте меняются вживую.
- **Экспорт и импорт** таймингов в файл, чтобы переносить их между ПК, телефоном и сценой Blender.

## Запуск на ПК без установки

Распакуйте архив и откройте `index.html` двойным кликом в Chrome или Edge.
Если карта не грузится или не работает геолокация, значит браузер ограничивает локальные файлы. Тогда используйте сайт из раздела ниже.

## Публикация на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на https://github.com.
2. Нажмите **+ → New repository**. Имя, например, `kostroma-lights`, тип **Public**, затем **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите все файлы из этой папки (`index.html`, `app.js`, `data.js`, `sw.js`, `manifest.webmanifest`, иконки). Затем **Commit changes**.
4. Откройте **Settings → Pages**. В **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-НИК.github.io/kostroma-lights/`.

## Установка на iPhone

Откройте адрес сайта в **Safari** → кнопка «Поделиться» → **«На экран „Домой“»**.
Появится иконка «Светофоры». Приложение откроется на весь экран и попросит доступ к геолокации.

## Установка на Android и ПК

В Chrome или Edge откройте сайт → меню → **«Установить приложение»**.

## Важно

- Тайминги хранятся на каждом устройстве отдельно. Переносите их через «Данные → Сохранить в файл / Загрузить из файла».
- Светофоры со временем отклоняются на несколько секунд, поэтому точку отсчёта стоит иногда обновлять.
- Подсказки не заменяют внимание на дороге: ориентируйтесь на реальный сигнал и соблюдайте ПДД.
